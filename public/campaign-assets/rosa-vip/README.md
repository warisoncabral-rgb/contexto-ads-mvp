# Rosa VIP test media

Three text-free, 4:5 assets prepared for the first hosted creative-package test.
They are derived from previously approved Rosa VIP visual directions and keep all
campaign copy in the structured creative variants instead of baking claims into
the image.

These images are synthetic test assets. Their safe area, dimensions, MIME type,
and checksum were verified, but exact product/catalog fidelity still requires a
human visual review before creative approval. This directory does not authorize
Meta writes, campaign publication, delivery, or spend.
